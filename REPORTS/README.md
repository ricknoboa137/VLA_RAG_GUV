# Reports

Written reports of measurements made with this repository, each in its own
folder with its figures and the data it was drawn from, so it can be rebuilt
and checked without the rest of the repository.

| Folder | Report |
|---|---|
| [`arm-benchmark/`](arm-benchmark/README.md) | SmolVLA against X-VLA on the SO-101 arm, open loop on held-out episodes |

The raw record of every measurement stays in `training/results/`; a report
copies only what it needs. A report carries no credentials, no account names
and no local paths, and none should be added.
